This happens because your Linux system manages Python packages through the OS package manager, so it doesn't want pip installing packages directly into the system Python.
--------Don't use---------
pip install fastapi uvicorn

Step 1 — Create a virtual environment:
python3 -m venv venv

Step 2 — Activate it:
source venv/bin/activate

Step 3 — Now install FastAPI:
pip install fastapi uvicorn
